An AI-powered full-stack web application that analyzes source code and provides intelligent feedback, fixes, and improvements using LLMs.

---

## ✨ Features

- 🔍 Automated Code Review  
- ⚡ AI-generated Issues, Fixes & Improvements  
- 💻 Interactive Code Editor with syntax highlighting   
- 🧠 Uses Groq (LLaMA 3.1) for fast AI inference  
- 🌐 Full-stack architecture (React + Node.js)
