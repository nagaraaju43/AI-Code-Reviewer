An AI-powered full-stack web application that analyzes source code and provides intelligent feedback, fixes, and improvements using LLMs.

---

## ✨ Features

- 🔍 Automated Code Review  
- ⚡ AI-generated Issues, Fixes & Improvements  
- 💻 Interactive Code Editor with syntax highlighting   
- 🧠 Uses Groq (LLaMA 3.1) for fast AI inference  
- 🌐 Full-stack architecture (React + Node.js)

---


## 🛠️ Tech Stack

### Frontend
- React.js
- PrismJS
- React Simple Code Editor
- CSS (custom UI)

### Backend
- Node.js
- Express.js

### AI
- Groq API (LLaMA 3.1)

---


## ⚙️ Setup & Installation

### 1. Clone Repo

```bash
git clone https://github.com/nagaraaju43/AI-Code-Reviewer.git
cd AI-Code-Reviewer
```

## 2. Backend Setup 

```bash
cd backend
npm install
nodemon app.js
```

### Create .env file:

```bash
GROQ_API_KEY=your_api_key_here
```

## 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### Usage
1. Enter code in the editor
2. Click Review
3. Get:
 ❌ Issues 
 ✅ Fix
 💡 Improvements
4. Copy or apply fixes
